# 🎬 YouTube Clone — Flexbox na Prática

Um projeto desenvolvido como parte dos desafios educacionais da **[DIO.me](https://www.dio.me/)**, com o objetivo de reproduzir o layout de uma página de vídeo do YouTube e colocar em prática os conceitos de **CSS Flexbox**.

Mais do que replicar uma interface conhecida, este projeto representa uma etapa da minha jornada de aprendizado em desenvolvimento Front-End, explorando a organização de elementos, o posicionamento de componentes e a construção de layouts com HTML e CSS.

## 🎯 Objetivo do projeto

O desafio proposto foi clonar a página do YouTube utilizando CSS, aplicando principalmente os conhecimentos adquiridos sobre Flexbox.

A proposta também foi dar identidade própria ao projeto, personalizando elementos da interface e utilizando um vídeo relacionado ao universo dos games.

## 🖥️ Sobre o projeto

A interface foi construída com base no layout de reprodução de vídeos do YouTube, incluindo:

- **Cabeçalho:** ícones de navegação, logotipo, campo de pesquisa e avatar de perfil.
- **Área principal:** vídeo incorporado, título, informações do canal e botões de interação visual.
- **Descrição do vídeo:** informações e texto descritivo sobre o conteúdo apresentado.
- **Vídeos recomendados:** lista lateral com miniaturas, títulos e informações dos vídeos.

O conteúdo principal escolhido foi um vídeo sobre *The Legend of Zelda: Twilight Princess* e o projeto Duskport, trazendo um toque pessoal à atividade.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização semântica do conteúdo.
- **CSS3:** estilização, espaçamento, alinhamento e apresentação dos componentes.
- **CSS Flexbox:** organização dos elementos em linhas e colunas, distribuição de espaço e alinhamento dos componentes.

## 📚 Conceitos praticados

Durante o desenvolvimento, foram trabalhados conceitos fundamentais para a construção de interfaces web:

- `display: flex` — ativação do modelo de layout Flexbox.
- `flex-direction` — definição da direção dos elementos.
- `justify-content` — distribuição dos elementos ao longo do eixo principal.
- `align-items` — alinhamento dos componentes no eixo transversal.
- `flex` e `flex-shrink` — controle do crescimento e da redução dos elementos.
- `gap` — espaçamento entre componentes.
- `flex-wrap` — quebra de linha dos elementos quando necessário.
- `min-width` e `max-width` — controle das dimensões dos componentes.
- `aspect-ratio` — manutenção da proporção do vídeo incorporado.

Também foram utilizados recursos de HTML para melhorar a identificação de elementos, como atributos `alt`, rótulos acessíveis e estruturação por seções.
